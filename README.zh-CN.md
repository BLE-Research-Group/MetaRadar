低功耗蓝牙（BLE）是一种广泛使用的无线协议，为您周围的各种设备提供支持——从耳机、智能手表、健身追踪器到 AirTag、物联网设备、游戏控制器，甚至现代情趣用品。BLE 设备通过广播小型数据包进行通信，其中可能包含设备标识符、元数据和其他连接所需的信息。

这些广播虽然对设备功能至关重要，但也可能被用来追踪您的存在和行动。例如，一副廉价的无线耳机可能会公开暴露一个持久标识符。任何在附近监听 BLE 数据包的人——无论是政府、公司还是恶意行为者——都可能在未经您同意的情况下利用这些信息追踪您。

幸运的是，许多现代设备在 BLE 中实现了隐私功能以防止追踪，例如随机化地址和有限广播。BLE Radar 帮助您区分保护您隐私的设备和可能被追踪的设备。通过分析您周围的 BLE 流量，应用让您了解哪些设备可以安全使用。

除了分析之外，BLE Radar 还可以实时保护您。当可疑设备在附近或某台设备随您移动一段时间时，应用可以提醒您，让您对潜在的跟踪或不必要的追踪获得早期预警。您可以根据设备标识符、类型或行为配置提醒，以满足您的安全需求。

开发这个应用的目标是让您能够了解和控制环境中的 BLE 设备。了解哪些设备正在广播可追踪信息、哪些注重隐私，能让您对日常使用、佩戴和交互的设备做出明智的决定。

应用主要功能：
* 扫描、分析和跟踪周围的蓝牙设备；
* 为雷达创建灵活的筛选条件；
* 对扫描到的 BLE 设备进行深度分析，从可用的 GATT 服务获取数据；
* GATT 服务浏览器；
* 通过元数据识别设备类型；
* 估算到设备的大致距离。

本应用不会共享您的个人数据或地理位置，所有工作均在离线状态下完成。
